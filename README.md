 FareCalc Travel Optimizer (Python)

 Description

FareCalc is a Python-based fare estimation system for a ride-sharing service. It calculates ride cost based on distance, vehicle type, and peak-hour surge pricing.

---

 Features

* Dictionary-based rate mapping
* Surge pricing (5 PM – 8 PM)
* Input validation (distance & time)
* Error handling for invalid vehicle types
* Continuous user interaction

---

 Concepts Used

* Functions
* Dictionaries
* Exception Handling
* Conditional Logic
* Loops

---

 How to Run

```bash
python farecalc.py
```

---

 Sample Output

```
----- PRICE RECEIPT -----
Vehicle Type   : Economy
Distance       : 10 km
Travel Hour    : 18
Surge Applied  : Yes (1.5x)
Final Fare     : Rs. 150.00
```

 Key Learning

Used dictionary mapping and modular functions to design a scalable fare calculation system with proper validation.
